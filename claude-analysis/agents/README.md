## Project Context

### Mirael Mission

Provide emotional clarity and cognitive insight to high-functioning women experiencing burnout and overwhelm, using evidence-based CBT principles in a non-therapeutic, empowering format.

### Target Demographic

High-achieving professional women (25-45) dealing with:

- Perfectionism and imposter syndrome
- Chronic overwhelm and decision fatigue
- Burnout and emotional exhaustion
- Difficulty setting boundaries
- Need for practical, actionable insights

### Technical Foundation

- **Frontend**: Next.js 15, React 19, TypeScript, TailwindCSS
- **Backend**: Supabase, PostgreSQL, Prisma ORM
- **AI**: OpenAI GPT integration with CBT-optimized prompts
- **Security**: End-to-end encryption for therapeutic content
- **Internationalization**: Support for English, French, Arabic
